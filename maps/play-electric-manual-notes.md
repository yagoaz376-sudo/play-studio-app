# Play Electric: what the reference manual says (and what the pedal shows)

Source: TC-Helicon *Play Electric Reference Manual*, firmware 1.0, 2014-07-16 (read on 2026-11-25).
The user's pedal runs newer firmware, so some lists differ: **the pedal is the authority** when they disagree.

## Behaviour
- **TALK:** press and hold HIT → TALK mode: all vocal effects bypassed, dry mic to the output.
  With a guitar plugged in → TALK/Tuner mode: guitar muted, tuner on, dry voice still passes.
  While in TALK the HIT LED flashes; **tap HIT once to return to normal**.
- **Looper:** hold DOWN and UP together to enter Loop mode.
  DOWN = PLAY / REC / overdub (hold DOWN = undo the last overdub); UP = STOP (hold UP = erase).
- **STORE:** press the Store button twice to save over the current preset.
- **Factory reset (Play Electric):** hold the two arrow buttons next to the Control knob while powering up
  (erases all preset changes; back up with VoiceSupport first). Not the Play Acoustic's STORE + BACK.

## Style lists
Same as the Play Acoustic (the app's existing lists are right): Harmony, Double, Vocal Reverb, HardTune,
Transducer, Vocal uMOD (manual says "Auto Filter" where the Acoustic data says "AUTO WAH"), Guitar Delay, Guitar Reverb.

**Vocal Delay — as shown on the user's pedal (newer than the manual):**
HALF, QUARTER, EIGHTH, TRIPLET, DOTTED 1/8, 1/4 TRIPLET, SIXTEENTH, PING PONG 1, PING PONG 2, PING PONG 3,
MULTITAP 1–6, CLASSIC SLAP, SET TIME (18; index 0 = HALF). The manual (fw 1.0) has no HALF.
